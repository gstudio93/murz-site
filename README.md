# MURZ — ремонт квартир в Ростове-на-Дону

Статический сайт студии ремонта: главная страница, статьи об услугах и интерактивный калькулятор.

## Публикация

Сайт публикуется через GitHub Pages. Workflow находится в `.github/workflows/pages.yml` и запускается автоматически при push в ветку `main`.

## Локальная проверка

Откройте `index.html` в браузере или запустите любой локальный статический HTTP-сервер из корня проекта.
